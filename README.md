# The Wild Oasis

Main project in Jonas Schmedtmann's Ultimate React Course. Built with React Query and Supabase.

## ⚙️ Project Overview: Admin Dashboard

This is a full-featured internal application used by hotel employees to manage cabins, bookings, and guests.

### 🚀 Key Technical Features
* **Remote State Management:** Handled via **React Query** for seamless data fetching, caching, and optimistic UI updates.
* **Complex Forms:** Managed with **React Hook Form** for efficient validation and submission.
* **Styling:** Fully custom-built design system using **Styled Components**.
* **Charts & Analytics:** Real-time data visualization using **Recharts**.
* **Advanced Features:** Multi-level filtering, pagination, sorting, and a global Dark Mode toggle.
